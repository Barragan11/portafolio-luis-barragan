# Portafolio personal — Luis Ángel Barragán González

Sitio web personal estático preparado para GitHub Pages.

## Archivos que debes agregar

En la raíz del repositorio coloca:

- `index.html`
- `styles.css`
- `script.js`
- `foto.jpg` → tu fotografía
- `cv-luis-barragan.pdf` → el PDF final descargado desde Canva

## Publicación

En GitHub:

Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` → `/ (root)` → Save.

El botón **Descargar CV** apunta a `cv-luis-barragan.pdf`, por lo que el archivo debe conservar exactamente ese nombre.
